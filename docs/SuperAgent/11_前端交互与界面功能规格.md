# 11. 前端交互与界面功能规格

> 本文档定义 SuperAgent Web 端的信息架构、页面路由、全量功能视图交互流程、实时流式通信与多端协作旁观体验、附件上传、安全渲染及双语国际化规范。所有描述面向产品交互与协议行为，不绑定任何前端构建工具或特定框架。

---

## 1. 信息架构与导航拓扑

Web 应用采用单页 Hash 路由（默认首页 `#todo`；历史 `#messages` 自动跳转 `#todo` 的消息标签页），依据当前登录用户角色（普通员工 vs `ADMIN`）动态呈现导航结构：

```text
顶部全局导航栏
├── 企业品牌 Logo ──────────────────────────────► #chat（自动选中个人 SuperAgent）
├── 待办首页 (#todo) [实时未读/待处理角标]
├── Agent 协作 (#chat)
├── 异步任务 (#tasks)
├── 自动化 (#automation)
├── 文件资产 (#files)
├── 工作空间下拉 ▼
│   ├── 项目空间 (#projects)
│   ├── 连接器 (#connectors)
│   ├── 技能库 (#skills)
│   └── 我的用量 (#usage)
├── 管理后台 (#users) [仅 ADMIN 可见] ──────────► 展开可折叠左侧管理边栏（折叠态持久化本地）
│   ├── 用户与组织 (#users)                      [标签页：用户增删改 | 组织架构树]
│   ├── 模型管理 [分组]
│   │   ├── 供应商配置 (#models)                 [CLI 目录、私有 Node、模型探活、密钥池排序]
│   │   └── 模型价格 (#model-prices)             [目录价、手动覆写、允许参与任务开关]
│   ├── 统计分析 [分组]
│   │   ├── 运营概览 (#analytics)                [14天趋势、成功率、按模型花费]
│   │   └── 公司用量 (#company-usage)            [全员 Token/USD、按人排行、系统探活]
│   └── 系统设置 [分组]
│       ├── 基础设置 (#settings)                 [企业品牌/Logo、公网URL、默认/备用模型、复杂任务上限、CodeBuddy地域]
│       ├── 企业集成 (#integrations)             [6大平台应用配置 + 含回调地址的一步步配置指引抽屉]
│       └── 文件存储 (#file-storage)             [存储渠道切换、实测探活、各渠道存量文件计数]
└── 个人账户菜单 ▼（用户信息卡片、所属部门、公司名称、账号设置、中/英语言切换、退出登录）
```

## 2. 认证入口、账号设置与双语国际化

### 2.1 登录与自助注册页 (`/login`)
- **4 种登录入口界面**：
  1. **组织 + 用户名 + 密码**（主路径；本地记忆上次输入的组织简称）；
  2. **手机短信验证码**（含 60 秒倒计时，后端预留）；
  3. **企业 SSO 跳转**（后端预留）；
  4. **微信扫码登录**（后端预留）。
- **企业自助注册 (`#register`)**：依据 `GET /api/v1/orgs/registration` 动态显隐；注册成功后在醒目弹窗中**一次性展示随机生成的 14 位管理员密码**并提供一键复制。
- **强制首次改密拦截**：登录态检出 `mustChangePassword = true` 或任意 API 返回 HTTP 403 `password_change_required` 时，锁定主应用界面并强制弹出改密表单，直至改密成功放行。
- **个人账户设置弹窗**：支持本地图片裁剪生成 `256×256` 正方形头像上传（≤1 MB）与修改密码。

### 2.2 国际化与安全内容渲染
- **双语支持**：完整内置英文（`en`，默认）与简体中文（`zh`）双语词条，语言偏好持久化在本地存储，切换后重载页面确保全部视图与日期格式同步切换。
- **内容渲染安全**：所有助手 Markdown 回复与文件预览均经 GFM 渲染 + 严格 HTML 净化（XSS 过滤）处理；代码块支持语法高亮；文本/HTML 文件预览强制以纯文本渲染并在沙箱中展示，杜绝跨站脚本执行。

## 3. 核心业务视图交互规格

### 3.1 待办首页与消息分诊 (`#todo`)
- **顶部 KPI 条**：展示「待确认 / 待办 / 未读提醒」实时计数及「今日 / 本周 / 本月 / 累计完成任务数」。
- **7 个聚合标签页**：`全部`、`待确认`、`待办`、`已完成`、`提醒`、`已忽略`、`原始消息`（展示最近 500 条飞书/钉钉入站事件，支持按优先级 `P0/P1/P2/IGNORE` 与处理态 `waiting/delivered/notified/todo/task/read/ignored` 组合筛选）。
- **快捷操作**：在待办卡片上直接点击「确认继续任务」、「一键将收件箱待办转为任务」、「标记已完成 / 忽略 / 重开」及「全部已读」。

### 3.2 Agent 与个人 SuperAgent 三栏工作台 (`#chat`)

1. **左栏（Agent 列表）**：
   - 个人 `SuperAgent` 以动态标识置顶固定；
   - 其余 Agent 按「项目分组 -> 我的 Agent -> 协作 Agent（显示人数角标 `👥 N`）」层级折叠展示；支持新建/编辑/删除 Agent 弹窗（选择头像、24 种性格预设或自定义人设、项目归位与技能多选）。
2. **中栏（对话流与内联交互卡片）**：
   - 渲染跨会话拼接的连续对话时间线（会话切换处展示分割标记）；
   - 每条助手回复支持：折叠式思考过程（`thinking`）、折叠式工具调用芯片（`tool_use`/`tool_result`）、复制原始 Markdown、**7 阶段耗时条**（悬停或展开查看 `prep/retry/startup/model/tools/output/save` 及逐工具耗时）、以及用户消息原地微调编辑。
   - **快捷确认回复按钮**：自动识别模型回复中的 `👉 下一步：回复「…」`、`要创建吗？`、`确认创建吗？`、`确认修改吗？` 等约定短语，渲染一键快捷回复按钮。
   - **6 类内联交互卡片**（实时从流式输出或关联接口锚定在对应 `messageId` 下方）：
     1. **任务创建/分派卡**：展示实时进度、状态与跳转任务详情；
     2. **工作文件保存卡**：展示文件名、图标、一键预览抽屉或下载；
     3. **SuperAgent 计划审批卡**：展示团队变更与任务分解方案，提供「确认执行」按钮（解锁服务端计划门禁）；
     4. **协作者邀请确认卡**：所有者点击「确认邀请」或「取消」；
     5. **技能删除确认卡**：请求者点击「确认删除」或「取消」；
     6. **任务完成回流通知卡**：展示后台任务交付摘要与直达链接。
   - **附件与发送器**：支持文件选择、剪贴板粘贴（兼容微信/飞书截图与文件）及拖拽；发送前先上传至文件库（单次最多 10 文件 × 50 MB，或纯图模式 5 图 × 5 MB），支持 `⌘/Ctrl+Enter` 发送；遇 `409 Conflict`（同 Agent 正在回复）自动恢复草稿不丢字；检测到服务重启遗留的未回复用户消息时标注提醒。
3. **右栏（详情抽屉与上下文面板）**：
   - **普通 Agent**：人设摘要、头像、协作者邀请入口、运行中任务面板、产出文件面板，以及详情抽屉（历史提示词与 `.md` 导出、长期记忆查看/编辑/清空/立即蒸馏、30 天/5000 条运行日志、会话轮换记录、成员与技能清单）。
   - **个人 SuperAgent**：后台事件循环实时状态与「后台记录抽屉」（按轮次分组展示外部/内部输入与后台回复）、近期分派任务，以及「工作台账抽屉」（按状态/成员筛选与单任务事件时间线展开）。

### 3.3 异步任务工作台 (`#tasks`)
- **列表页**：分页 20 条/页，支持状态/来源/项目/Agent/主题标签芯片筛选并实时计算当前筛选集合的汇总美元花费；复杂任务行支持就地展开折叠子任务树。
- **详情页（8 大标签页 + 右侧信息栏 + 底部交互栏）**：
  - `提示词`：完整任务说明与已预读资料链接；
  - `模型选型`：完整展示每次路由决策（`judge`/`user`/`fallback`/`escalation`/`default`/`fixed`）、裁判模型、候选价格清单与决策理由；
  - `执行过程`：编码任务置顶展示 `PRD -> 开发 -> 验收` 三步进度卡片；合并展示流式正文、折叠工具调用组与 1 秒跳动静默计时器；
  - `交付输出`：渲染最终 `output.md` 或验收证据；
  - `子任务`：复杂任务全部子任务状态、花费与跳转；
  - `费用明细`：按模型、按运行步次及子任务拆分的 Token 与 USD 账单；
  - `耗时分析`：融合等待排期/等待用户/等待子任务与各执行回合的完整甘特时间线；
  - `会话信息`：工作区路径、CLI 引擎、会话池状态（`busy`/`reserved`/`idle`/`in_use`/`released`）。
  - **底部交互**：处于 `NEEDS_CONFIRMATION` 时置顶一键确认答复条；支持带附件的追问纠偏输入与「基于结论续做 (`Carry on`)」新建关联任务弹窗。

### 3.4 自动化、文件、项目、技能与连接器视图
- **自动化 (`#automation`)**：按类型/归属/关键字筛选，支持行内启停、立即运行、编辑与删除；抽屉编辑器提供常用 Cron 快捷模板（每小时/每天/工作日/每周/每月/自定义）、时区选择、重叠策略选择与 **250ms 防抖服务端实时预演未来 3 次触发时刻**；API 类型详情页展示一次性的触发令牌与即拿即用的 `curl` 调用示例。
- **文件资产 (`#files`)**：左侧个人 3 层目录树支持**拖拽文件归档**及虚拟只读「按 Agent 浏览」视图；主区支持按类型标签页、项目、Agent、关键词与多标签 AND 组合过滤，全屏拖拽上传；内置**分屏实时 Markdown 编辑器**（250ms 预览防抖）与**侧滑预览抽屉**（支持 Frontmatter、语法高亮、图片/视频流、PDF iframe、行内标签编辑与移目录）。
- **项目空间 (`#projects`)**：活跃/已归档双标签卡片网格；详情含 `Agent`、`任务`、`文件`、`成员` 四视图及归档/重开操作。
- **技能库 (`#skills`)**：支持按企业/个人空间、创建人、启停状态与「我的技能」筛选；侧滑编辑器支持权限分级选空间、上传配图并自动在光标处插入 `![说明](images/<名>)`。
- **连接器 (`#connectors`)**：智能将飞书消息机器人与 `feishu-docs` OAuth 合并为同一视觉卡片；支持生成 8 位绑定码、OAuth 跳转授权与回跳提示 Toast、个人令牌配置（Confluence 自动提示 Cloud 邮箱与自建 PAT 区别）、MCP 工具能力检查抽屉（展示只读/破坏性标签与参数 Schema）及管理员自定义 MCP 增删改。

### 3.5 用量报表与管理后台视图
- **个人与公司用量 (`#usage` / `#company-usage`)**：支持 `本月 / 1 / 7 / 30 / 90 天` 切换，展示估算美元总额、总 Token 与缓存命中率卡片、按日堆叠柱状图（未命中输入 / 缓存读 / 缓存写 / 输出），以及按 Agent、按任务、按员工（管理端）与系统探活钻取表。
- **供应商与价格 (`#models` / `#model-prices`)**：CLI 目录卡片与在线安装/升级实时日志抽屉、私有 Node.js 状态条、3 标签供应商详情（基础信息 / 逐模型推理探活状态 / 支持拖拽排优先级的 API Key 池）；价格页支持行内编辑手动覆盖价与切换 `forTasks` 路由开关。
- **运营概览、集成、存储与基础设置 (`#analytics` / `#integrations` / `#file-storage` / `#settings`)**：完整覆盖后台各项管理表单、实测探活按钮与可复制回调地址。

## 4. 实时通信与前端轮询策略汇总

| 交互场景 | 通信协议 | 节拍与防抖策略 | 断线与协作行为 |
|---|---|---|---|
| **对话发送回复** | `POST /sessions/{id}/messages` (SSE) | 流式逐帧渲染 | 切走页面仅中断前端拉流，**服务端继续执行完本轮** |
| **断线重连 & 同事同屏旁观** | `GET /sessions/{id}/live` + `/live/stream` (SSE) | 活跃检测每 **2.5 秒** | 检测到运行中立即接入 `/live/stream` 完整回放缓冲并续收增量，重连本人与协作者共用同一逻辑 |
| **SuperAgent 主控面板** | 轮询 `/superagent` + `/history` | 每 **3 秒**（流式生成或标签页隐藏时暂停） | 基于内容指纹 diff 决定是否重绘，避免打断用户滚动阅读 |
| **普通 Agent 任务侧栏** | 轮询 `/agents/{id}/tasks` | 活跃 **5 秒** / 空闲 **15 秒** | 实时更新内联任务卡与侧栏进度 |
| **记忆蒸馏进度** | 轮询 `/agents/{id}/memory` | 蒸馏中每 **3 秒** | `distilling` 变为 `false` 自动停止 |
| **异步任务详情实时日志** | 串行轮询 `/events?offset=` + `/status` | 活跃期每 **1.5 秒**（串行防重入） | 仅拉取增量偏移事件，终态自动停轮询 |
| **待办首页角标与列表** | 轮询 `/notices` + `/notices/stats` | 每 **60 秒** | 刷新顶栏待处理角标 |
| **CLI 安装/升级日志** | 轮询 `/install-log` | 安装中高频轮询 | 进程结束后自动刷新供应商状态 |
| **Cron 预览 / Markdown 预览** | 节流/防抖 | **250 ms** 防抖 | 避免敲键风暴 |
